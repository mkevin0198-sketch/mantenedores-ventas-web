# Mantenedores de ventas

Aplicación HTML para Equipo Interno e Infosiniestros.

## Uso

Esta versión pública comienza sin registros. Abre la página y pulsa **Subir Excel** para cargar uno o ambos mantenedores en formato `.xlsx`. Equipo Interno y Vida y Salud se reúnen en Equipo Interno; Infosiniestros permanece separado. Los AURIS duplicados se omiten.

El Excel se procesa en tu navegador y no se envía a GitHub. Los registros se guardan en ese navegador y dispositivo; no se sincronizan entre computadoras. Puedes registrar ventas manualmente, cargar capturas, filtrar fechas y exportar el mantenedor actualizado a Excel. La lectura de imágenes necesita internet para cargar el lector OCR.

La aplicación y sus plantillas de exportación no contienen nombres ni registros reales. La importación no inventa el resultado de Venta si no existe en el Excel. Conserva los datos del navegador y utiliza la exportación Excel para respaldar tus registros.
